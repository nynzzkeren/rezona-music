# Rezona

**Rezona** is an Android music application featuring an **Obsidian Silver** monochrome design system and hardware-accelerated **Liquid Glass** architecture.

## Design Highlights
- **Strict Monochrome Palette**: Built upon Obsidian Black (`#08090B`), Deep Charcoal (`#111318`), Graphite (`#1C1F26`), Smoky Silver (`#858B96`), Pearl White (`#F4F5F7`), and Soft Silver (`#C4C8D0`) with Pure White (`#FFFFFF`) specular rims.
- **Hardware-Accelerated Liquid Glass**: Real-time backdrop blur powered by Chris Banes' Haze library (`dev.chrisbanes.haze:haze` + `haze-materials`).
- **Typography**: Geometric modernism with bundled **Satoshi** font family (Regular, Medium, Bold).
- **Audio Engine**: AndroidX Media3 ExoPlayer integration for seamless playback.
